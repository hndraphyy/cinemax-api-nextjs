# 🎬 CineMax (Technical Exploration)

This repository is a dedicated **learning project** focused on mastering API integration within the **Next.js** ecosystem. The main goal was to practice asynchronous data fetching from the TMDB API and implementing a type-safe architecture using **TypeScript**.

> ⚠️ **Note:** This is a logic-heavy project. Styling is kept minimal as the primary focus was on the backend-frontend data flow and Next.js App Router mechanics.

## 🧪 Learning Objectives
- Implementing **Server-Side Fetching** in Next.js.
- Handling complex API responses from TMDB.
- Defining strict **TypeScript Interfaces** for movie data.
- Managing environment variables for API security.

## 🛠️ Tech Stack
- **Framework**: Next.js (App Router)
- **Language**: TypeScript (.tsx)
- **Styling**: Tailwind CSS (Basic layout)
- **API**: TMDB API

## 🚀 How to Run (For Testing)
1. Clone the repo.
2. Install dependencies: `npm install`.
3. Add your `TMDB_API_KEY` to a `.env` file.
4. Run: `npm run dev`.
